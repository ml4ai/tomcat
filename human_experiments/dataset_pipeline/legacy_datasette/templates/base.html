This is the archived ToMCAT dataset site. It is frozen at the 2025-03-09 release and is no longer updated. Current work lives at tomcat.lab.pyarelal.xyz, which serves directly from the PostgreSQL database rather than from a periodically exported SQLite file.

Three differences matter before you use this copy:

  • screen_capture holds 347,093 rows here against 4,125,377 in the current build. The 2025-03-09 rebuild dropped about 92% of that table; this was a defect, not a filtering decision.
  • ekg_sync is missing one station entirely: session exp_2023_04_17_13, station leopard (1,026,490 rows). That session and station both appear in the neighbouring signal tables, so a query returns an empty result here rather than an obvious gap.
  • audio_vocalics column names differ (mfcc_sma_1_ here, "mfcc_sma[1]" there), so queries written against one site do not port unchanged to the other.

Full-database downloads are still served from this site for now.
